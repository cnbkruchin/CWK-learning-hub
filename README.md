# CWK Learning Hub — ระบบจัดเก็บข้อมูลและส่งงาน

ระบบรับส่งงานและจัดเก็บข้อมูลการเรียนสำหรับโรงเรียนจุนวิทยาคม (ชื่อโรงเรียน/ระบบแก้ได้)
ออกแบบตาม Master Prompt ([docs/requirements/master-prompt.md](docs/requirements/master-prompt.md))
โดยใช้ **Google Apps Script** เป็นเซิร์ฟเวอร์และหน้าเว็บ, **Google Sheets** เป็นฐานข้อมูล และ **Google Drive** เก็บไฟล์

> สถานะ: รอบแรก — ระบบจัดเก็บข้อมูลและการส่งงาน (งานเดี่ยว งานกลุ่ม ไฟล์ การตรวจรับงาน) พร้อมโมดูลคำนวณคะแนน
> ทดสอบกับบริการ Google จำลองและเบราว์เซอร์จริงแล้ว **ยังไม่ได้ทดสอบบนบัญชี Google จริง และยังไม่พร้อมใช้งานจริง**
> ดูสิ่งที่ทำแล้ว/ยังไม่ทำใน [docs/07-traceability.md](docs/07-traceability.md)

## ทำอะไรได้แล้ว

**นักเรียน** (ใช้บนมือถือได้)
- เข้าระบบด้วยรหัสนักเรียน + รหัสผ่าน (ไม่ต้องมีอีเมล) ดูรายวิชาและงานพร้อมสถานะ
- อัปโหลดหลายไฟล์/ถ่ายภาพ มีแถบความคืบหน้า แจ้งชนิด/ขนาดที่รับก่อนอัปโหลด อัปโหลดต่อได้เมื่อเน็ตสะดุด
- ไฟล์เข้าฉบับร่างก่อน → กด "ส่งงาน" → ได้ **ใบยืนยัน** (รหัสการส่ง เวลาเซิร์ฟเวอร์ รายการไฟล์)
- ส่งใหม่เป็นรุ่นใหม่ รุ่นเดิมเก็บครบ กดซ้ำไม่สร้างรายการซ้ำ
- งานกลุ่ม: สร้างกลุ่ม เชิญ/ตอบรับ ขอเข้าร่วม ส่งแทนกลุ่ม ป้องกันเพื่อนส่งทับกัน
- แฟ้มงานของตนเอง (รวมงานกลุ่ม)

**ครู**
- สร้าง/แก้ภาระงาน (คะแนนเต็มกับน้ำหนักแยกกัน วันเปิด/กำหนดส่ง/ปิดรับ ชนิดไฟล์ จำนวนไฟล์ จำนวนครั้ง ลิงก์ กติกากลุ่ม)
- คิวตรวจงาน นับผู้ส่ง/ส่งช้า/ยังไม่ส่ง เปิดดูรูปและ PDF ในหน้า รับรุ่นเพื่อประเมินหรือส่งคืนแก้ไข
- ขยายเวลารายคน/รายกลุ่ม จัดการกลุ่ม ย้ายสมาชิกหลังตรึง (ดูผลกระทบก่อนยืนยัน) คัดลอกกลุ่มจากงานก่อน
- ครูร่วมสอนทำได้ตามสิทธิ์ที่ได้รับ

**ผู้ดูแล**
- ดูพื้นที่ Drive และจำนวนไฟล์ ตั้งเพดานไฟล์ ชนิดไฟล์ อายุการเก็บ โควตา รีเซ็ตรหัสผ่าน ปิดบัญชี
- สำรองฐานข้อมูลรายวัน ล้างไฟล์กำพร้า แจ้งเตือนพื้นที่ใกล้เต็ม (งานตั้งเวลา)

## เริ่มต้นเร็ว

```bash
npm test            # ทดสอบ 64 กรณี (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้ Node.js 18+)
npm run dev         # ทดลองหน้าเว็บที่ http://localhost:8080 พร้อมข้อมูลสมมติ (บัญชีทดสอบพิมพ์ในหน้าจอ)
npm run test:e2e    # ทดสอบหน้าเว็บในเบราว์เซอร์ (ต้องมี Playwright)
npm run docs:schema # สร้าง docs/02-data-model.md ใหม่หลังแก้ gas/Schema.js
```

ติดตั้งบน Google: `clasp push` → รัน `setup` → รัน `installTriggers` → Deploy เป็น Web app (Execute as: Me) — รายละเอียดใน [06-deployment.md](docs/06-deployment.md)

## หลักการสำคัญของการออกแบบ

- ตรวจสิทธิ์ที่เซิร์ฟเวอร์ทุกคำขอ (บทบาท + ความสัมพันธ์กับรายวิชา) รวมถึงการเปิดไฟล์
- ใช้เวลาเซิร์ฟเวอร์เท่านั้น เก็บ UTC แสดงเวลาไทย ปี พ.ศ.
- ข้อมูลทุกเซลล์เป็นข้อความ: รหัส `00123` ไม่หาย ข้อความที่ขึ้นต้นด้วย `=` ไม่กลายเป็นสูตร
- ธุรกรรมบน Sheets: ล็อก + ตรวจรุ่น + journal ย้อนกลับ/กู้คืน — บันทึกครบหรือไม่บันทึกเลย
- ไม่ลบหลักฐาน: ส่งซ้ำเป็นรุ่นใหม่, ย้ายสมาชิกสร้าง snapshot ใหม่, ปิดบัญชีไม่ลบงาน
- ไฟล์อยู่ใน Drive ส่วนตัวของบัญชีระบบ ไม่แชร์ ตรวจชนิดจริง กักไฟล์ที่ไม่ผ่าน ดาวน์โหลดผ่านตั๋วชั่วคราว
- คำนวณคะแนนจากโมดูลเดียว ด้วยทศนิยมแม่นยำ ปัดครั้งเดียว

## ระยะถัดไป (ตามข้อ 18 ของข้อกำหนด)

1. จัดการบัญชี ปีการศึกษา รายวิชา ทะเบียน และ Import Wizard (XLSX/CSV) — จำเป็นก่อนใช้ข้อมูลจริง
2. สมุดคะแนน ให้คะแนน/รูบริก กระจายคะแนนกลุ่มและปรับรายคน ประกาศ/เรียกคืนคะแนน รุ่นนโยบายคะแนน
3. แดชบอร์ดสถิติ ปิดผลรายวิชา snapshot รายงาน PDF (ภาษาไทย) และ XLSX
4. ย้ายข้อมูลปีเก่า ทดสอบบน Apps Script จริงและทดสอบโหลด
