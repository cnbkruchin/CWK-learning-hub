# คู่มือใช้งานฉบับย่อ

## ผู้ดูแลระบบ

**เตรียมระบบ (ครั้งแรก)**
1. เข้าสู่ระบบด้วยบัญชีผู้ดูแลและรหัสชั่วคราวจาก `setup` แล้วตั้งรหัสผ่านใหม่
2. **รายวิชาและภาคเรียน** → เพิ่มปีการศึกษา (ระบบสร้างภาคเรียน 1 และ 2 ให้) และเพิ่มรายวิชาในหลักสูตร
3. **ครูและผู้ดูแล** → เพิ่มครู ระบบสร้างบัญชีและแสดงรหัสผ่านชั่วคราว **ครั้งเดียว** (ดาวน์โหลด CSV เพื่อแจกได้)
4. **นักเรียน** → เพิ่มทีละคน หรือ **นำเข้าจาก Excel / CSV**
   - คัดลอกตารางจาก Excel (แถวแรกเป็นหัวตาราง เช่น `รหัสนักเรียน ชื่อ นามสกุล ชั้น ห้อง เลขที่`) วางลงช่อง แล้วกด "ตรวจสอบข้อมูล"
   - ดูผลรายแถว (เพิ่มใหม่/แก้ไข/ข้าม/ผิด) แก้แถวผิดก่อน หรือเลือก "นำเข้าเฉพาะแถวที่ถูกต้อง" แล้ว "ยืนยันนำเข้า"
   - ถ้าคอลัมน์รหัสใน Excel เป็นตัวเลข เลข 0 หน้ารหัสอาจหายไป ให้ตั้งคอลัมน์เป็นข้อความก่อนคัดลอก (ระบบเตือนเมื่อรหัสยาวไม่เท่ากัน และไม่เติมศูนย์ให้เอง)
5. **รายวิชาและภาคเรียน** → "เปิดรายวิชาให้ครู" (หรือให้ครูเปิดเอง)

**การสมัครใช้งานของนักเรียน (ไม่บังคับ)** — หน้า **คำขอลงทะเบียน** เปิด "ให้นักเรียนสมัครใช้งาน" และตั้งรหัสลงทะเบียนได้
นักเรียนสมัครจากหน้าเข้าสู่ระบบ คำขอทุกรายการต้องกด **อนุมัติ** ก่อนจึงเข้าสู่ระบบได้ (ถ้ามีทะเบียนรหัสนั้นอยู่แล้ว ระบบผูกบัญชีกับทะเบียนเดิม)

**สิทธิ์ให้คะแนนของผู้ดูแล** — ผู้ดูแลให้/แก้คะแนนแทนครูได้เมื่อมีบทบาท "ผู้ดูแลคะแนน" (ผู้ดูแลคนแรกได้ตั้งแต่ติดตั้ง) ให้หรือถอนได้ที่หน้า **ครูและผู้ดูแล** ทุกการแก้คะแนนมีประวัติ

**รายงาน** — หน้า **รายงาน PDF / Excel**: สรุปคะแนนรายห้อง (ทุกรายวิชา), สมุดคะแนนรายวิชา (แยกตามห้อง/รวม), ผลประเมินงานกลุ่ม (แยกตามกลุ่ม)
กด "ดูรายงาน / PDF" → "พิมพ์ / บันทึกเป็น PDF" แล้วเลือกปลายทาง **บันทึกเป็น PDF** หรือกด "Excel (.xlsx)"

## ครู

1. **รายวิชาที่สอน** → "+ เพิ่มรายวิชาที่สอน" เลือกภาคเรียน รายวิชา (หรือเพิ่มรายวิชาใหม่) กลุ่มเรียน และวิธีคำนวณคะแนน — ครูเป็นครูเจ้าของรายวิชาอัตโนมัติ เปิดได้หลายวิชา
2. แท็บ **นักเรียน** → เลือกห้อง/ค้นหา ติ๊กเลือกนักเรียน (หรือเลือกทั้งหมด) → "ลงทะเบียนนักเรียนที่เลือก"
   หรือเปิด **รหัสเข้าร่วมรายวิชา** ให้นักเรียนลงทะเบียนเอง · ถอนนักเรียนต้องระบุเหตุผล (งานและคะแนนเดิมยังอยู่)
3. แท็บ **กลุ่มประจำรายวิชา** → สร้างกลุ่มและเลือกสมาชิก ย้ายสมาชิก ตั้งหัวหน้า สุ่มจัดกลุ่ม
   ตั้งค่าได้ว่า หัวหน้ากลุ่มเพิ่มสมาชิกทันทีหรือต้องส่งคำเชิญ จำนวนสมาชิกสูงสุด และล็อกกลุ่ม
4. แท็บ **ภาระงาน** → "+ สร้างภาระงาน" เลือกประเภท งานเดี่ยว / งานกลุ่ม / สอบ / รับคะแนนอย่างเดียว
   งานกลุ่มเลือก "ใช้กลุ่มประจำรายวิชา" เพื่อให้กลุ่มเดิมทำได้หลายงาน (หรือให้นักเรียนจัดกลุ่มเฉพาะงานนี้)
5. **ให้คะแนน** (ปุ่มในแต่ละงาน หรือแท็บสมุดคะแนน)
   - งานเดี่ยว/สอบ: พิมพ์คะแนนแล้วกด Enter ไปคนถัดไป เลือกสถานะ ยังไม่ส่ง/ยกเว้น (ต้องมีเหตุผล) → "บันทึกคะแนน"
   - งานกลุ่ม: ใส่คะแนนกลุ่ม → ตรวจหน้าตัวอย่าง → ยืนยัน ระบบบันทึกคะแนนกลุ่มไว้ที่กลุ่ม และให้สมาชิกทุกคนได้คะแนนเท่ากันอัตโนมัติ (ไม่หารจำนวนสมาชิก)
   - "ปรับรายคน" พร้อมเหตุผล เมื่อสมาชิกมีส่วนร่วมต่างกัน คะแนนที่ปรับไม่ถูกเขียนทับเมื่อแก้คะแนนกลุ่ม จนกว่าจะเลือก "ใช้คะแนนกลุ่ม"
6. **ประกาศคะแนน** — นักเรียนเห็นเฉพาะคะแนนที่ประกาศ แก้หลังประกาศต้องกดประกาศอีกครั้ง เรียกคืนการประกาศต้องมีเหตุผล
7. แท็บ **สมุดคะแนน** — ดูคะแนนทุกงาน คะแนนรวม (100) และเกรด คลิกคะแนนเพื่อดูที่มาและประวัติการแก้
8. แท็บ **รายงาน** — สมุดคะแนนแยกตามห้อง/รวม และผลประเมินงานกลุ่ม เป็น PDF หรือ Excel

## นักเรียน

1. เข้าสู่ระบบด้วยรหัสนักเรียนและรหัสผ่าน (ครั้งแรกต้องตั้งรหัสผ่านใหม่) หรือกด "สมัครใช้งาน" ถ้าโรงเรียนเปิดให้สมัคร
2. หน้า **รายวิชาของฉัน** → ใส่ "รหัสเข้าร่วมรายวิชา" ที่ครูให้ เพื่อลงทะเบียนเรียนเอง
3. ในรายวิชา แท็บ **กลุ่มของฉัน**
   - ยังไม่มีกลุ่ม: ตอบรับคำเชิญ หรือ "สร้างกลุ่มใหม่" (ผู้สร้างเป็นหัวหน้ากลุ่ม)
   - หัวหน้ากลุ่ม: ติ๊กเลือกเพื่อนที่ยังไม่มีกลุ่ม → "ส่งคำเชิญ" (หรือ "เพิ่มเข้ากลุ่ม" ถ้าครูอนุญาต) นำสมาชิกออกได้จนกว่าครูจะล็อกกลุ่ม
   - หนึ่งคนอยู่ได้หนึ่งกลุ่มต่อรายวิชา และกลุ่มนี้ใช้กับงานกลุ่มทุกงานที่ครูตั้งให้ใช้กลุ่มประจำรายวิชา
4. แท็บ **งาน** → เปิดงาน อัปโหลดไฟล์/ถ่ายภาพ → กด "ส่งงาน" และเก็บรหัสยืนยัน (งานกลุ่มสมาชิกคนใดก็ส่งแทนกลุ่มได้ เว้นแต่ครูกำหนดให้หัวหน้าส่ง)
5. แท็บ **คะแนนของฉัน** → คะแนนที่ครูประกาศแล้ว และคะแนนสะสม (ยังไม่ใช่ผลสุดท้ายจนกว่าจะครบทุกงาน) นักเรียนไม่เห็นคะแนนของเพื่อน
